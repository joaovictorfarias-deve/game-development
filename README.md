# 🎮 Game Development

Repositório dedicado aos meus estudos e projetos de desenvolvimento de jogos, reunindo experimentos, exercícios e jogos criados durante minha jornada de aprendizado.

## 🎯 Objetivo

Desenvolver conhecimentos em programação e criação de jogos, explorando mecânicas, sistemas, lógica de programação e ferramentas utilizadas no desenvolvimento de jogos digitais.

## 🛠️ Tecnologias e ferramentas

- **C#:** programação e desenvolvimento de mecânicas de jogos.
- **Unity:** criação e desenvolvimento de jogos.
- **Git:** controle de versão.
- **GitHub:** armazenamento e documentação dos projetos.

## 📚 Conteúdos que pretendo estudar

- Fundamentos de desenvolvimento de jogos;
- Lógica de programação aplicada a jogos;
- C#;
- Programação orientada a objetos;
- Unity;
- Movimentação de personagens;
- Sistemas de colisão;
- Física de jogos;
- Inteligência artificial para jogos;
- Interfaces e menus;
- Desenvolvimento de mecânicas.

## 📁 Projetos

Este repositório será utilizado para documentar minha evolução no desenvolvimento de jogos, reunindo exercícios, protótipos e projetos completos.

## 🚀 Objetivos de aprendizado

- Aprender C# aplicado ao desenvolvimento de jogos;
- Dominar os fundamentos da Unity;
- Criar minhas próprias mecânicas;
- Desenvolver jogos completos;
- Construir um portfólio na área de Game Development.
